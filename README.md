# 立命館大学シラバス データ自動生成

GitHub Actions を使用して立命館大学のシラバスデータを自動取得し、GitHub Pages で JSON として公開するリポジトリです。

## 仕組み

1. **Playwright** でシラバスサイト（https://syllabus.ritsumei.ac.jp/syllabus/s/）を巡回
2. 全学部 × 全曜日 × 全時限の組み合わせで授業情報を取得
3. JSON ファイルとして `data/` ディレクトリに出力
4. GitHub Pages の `gh-pages` ブランチに自動デプロイ

## 出力ファイル

| ファイル | 内容 |
|---------|------|
| `syllabus.json` | 全学部の授業データ |
| `syllabus_{学部名}.json` | 学部別の授業データ |

```json
{
  "lastUpdated": "2026-04-06T00:00:00+00:00",
  "year": 2026,

  "courses": [

      "faculty": "薬学部",
      "term": "春セメスター",

      "language": "日本語",
      "credits": "2",
      "syllabusUrl": "https://syllabus.ritsumei.ac.jp/syllabus/s/r-syllabus/..."
    }
  ]
}
```

## 自動実行スケジュール

- 毎週日曜日 深夜3時（JST）に自動実行
- GitHub Actions の「Run workflow」ボタンで手動実行も可能

## セットアップ

1. このリポジトリをフォーク
2. Settings → Pages → Source を `gh-pages` ブランチに設定
3. Actions タブから手動実行、または日曜日の自動実行を待つ
4. `https://{ユーザー名}.github.io/{リポジトリ名}/syllabus.json` でアクセス可能

## ローカル実行

```bash
pip install playwright
playwright install chromium
python scrape.py
```

## 環境変数

| 変数 | 説明 | デフォルト |
|------|------|-----------|
| `SCRAPE_YEAR` | 取得する年度 | 現在の年 |
| `SCRAPE_FACULTIES` | 対象学部（カンマ区切り） | 全学部 |
| `OUTPUT_DIR` | 出力ディレクトリ | `data` |

著作権およびデータの取り扱いについて
データの出典
本リポジトリで取得・公開している講義情報は、立命館大学 シラバス検索システム（一般公開用）を情報源としています。
• 出典元URL: https://syllabus.ritsumei.ac.jp/syllabus/s/
著作権の帰属
• 本データに含まれる講義内容、シラバス本文、および関連する情報の著作権は、学校法人立命館、または各授業を担当する教員に帰属します。
• 本プロジェクトは、著作権法で保護される「思想または感情を創作的に表現した」文章（授業概要や計画の詳細など）の保持・再配布を避け、**科目名・教員名・教室などの「事実（メタデータ）」の提供および公式シラバスへの誘導（URLの提示）**に留めています。
本プロジェクトの目的とサーバー負荷への配慮
本リポジトリは、学生による自作アプリケーション開発における以下の課題を解決するために運用されています。
1.	大学サーバーへの負荷軽減: 各アプリが個別にリアルタイムスクレイピングを行うのではなく、本リポジトリが週1回のみ一括取得し、GitHub Pages（CDN）経由で配信することで、大学側のシステム負荷を大幅に削減します。
2.	安定したデータ提供: ネットワーク環境やサイト構造の変化に強い、安定したデータアクセス手段を学生エンジニアに提供します。
免責事項
• 非公式プロジェクト: 本プロジェクトおよび提供されるJSONデータは、個人による非公式のものであり、学校法人立命館とは一切関係ありません。本データに関して大学側へ問い合わせを行うことはお控えください。
• 情報の正確性: データの取得には万全を期しておりますが、シラバスの更新タイミングやスクレイピングの特性上、内容が最新でない、あるいは誤りを含む可能性があります。履修登録等の重要な判断にあたっては、必ず大学公式の「manaba+R」および公式シラバスを確認してください。

• 運用の中止: 大学側からの要請や規約の変更、その他諸事情により、予告なく本データの公開を停止する場合があります。
